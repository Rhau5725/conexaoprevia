# Conexão Modas — Loja da Janilce

Site de prévia da Loja da Janilce, em Prados, MG.

Página estática em HTML e CSS, com a logo da loja e links de contato pelo WhatsApp.
A fotografia de moda é ilustrativa e carregada do Unsplash.

## Desenvolvimento

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP local.
Não requer instalação de dependências nem etapa de build.

## Vercel

Importe o repositório usando o preset **Other** e a pasta raiz.
O arquivo `vercel.json` configura a publicação estática.
